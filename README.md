# 🎲 Random GIF Generator

A modern and responsive **Random GIF Generator** built with **React**, **Tailwind CSS**, **Axios**, **Vite**, and the **GIPHY API**.

This application allows users to generate random GIFs instantly or search for GIFs based on specific tags. It demonstrates API integration, custom React hooks, reusable components, asynchronous data fetching, and responsive UI development.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Arsh173/random-gif-generator.git
```

Navigate to the project directory:

```bash
cd random-gif-generator
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the project root and add your GIPHY API key:

```env
VITE_GIPHY_API_KEY=your_giphy_api_key
```

Start the development server:

```bash
npm run dev
```
